# Backend — ML Scoring Pipeline

AI для справедливых субсидий | Decentrathon 5.0

## Быстрый старт

```bash
# 1. Установка
cd backend
pip install -r requirements.txt

# 2. Обучение модели
python train.py          # → model.pkl

# 3. Запуск API
uvicorn main:app --reload
# Swagger: http://localhost:8000/docs
```

## Model Card

### Алгоритм
**XGBClassifier** (XGBoost) — выбран по grid search из 7 конфигураций

- `max_depth=2`, `n_estimators=800`, `learning_rate=0.02`
- `reg_lambda=10`, `reg_alpha=3`, `min_child_weight=50`
- `subsample=0.7`, `colsample_bytree=0.6`, `scale_pos_weight=auto`

### Целевая переменная
`completion_rate` — бинарный: 1 если статус заявки "Исполнена", 0 если "Отклонена"/"Отозвано".
Статусы "Одобрена", "Получена", "Сформировано поручение" исключены из обучения.

### Данные
- **Источник:** subsidy.plem.kz — реальные данные животноводства РК 2025-2026
- **Train:** 2025 данные — 24 653 заявки (positive rate 82.4%)
- **Validation:** temporal hold-out 2026 — 1 332 заявки (positive rate 51.5%)

### Метрики

| Метрика | Val 2026 |
|---------|----------|

Калибровка: 6/8 бинов в пределах +/-10% от реальной вероятности.

### Fairness метрики

| Метрика | Значение | Интерпретация |
|---------|----------|---------------|
| Gini (ML баллы) | 0.1422 | Низкое неравенство |
| Gini (суммы) | 0.7149 | Высокое неравенство |
| Kruskal-Wallis регионы | H=7198.42, p=0.0 | Значимые различия |
| Kruskal-Wallis направления | H=2512.21, p=0.0 | Значимые различия |

Outlier-регионы (|z|>1): Акмолинская, Алматинская, Жамбылская области.

### Ограничения модели

1. Обучена только на данных животноводства Казахстана
2. Distribution shift: train 82.4% positive -> val 51.5% positive
3. Не учитывает качество животных, ветеринарные показатели и внешние факторы
4. Инструмент поддержки принятия решений, НЕ автоматическое решение о субсидировании
5. Агрегаты по группам могут быть нерепрезентативны для малых районов
